06 · Metodología

Por qué este dato es distinto

Este informe no agrega avisos: los verifica. Cada número de las páginas anteriores pasó por este proceso, todas las noches.

Lo que hacemos

  • Verificación nocturna: cada aviso se contrasta contra el portal; las bajas se confirman, no se asumen.
  • Un solo tipo de cambio: todos los precios normalizados — comparables entre sí aunque el aviso original mezcle dólares billete, transferencia o bolivianos.
  • Deduplicación: el mismo depto publicado por 3 agencias cuenta una sola vez.
  • Identificación por edificio: 87% de los avisos anclados a un edificio real georreferenciado — por eso existe la sección 04.
  • n declarado siempre: cada mediana dice cuántos avisos la sostienen; cuando el n es débil, lo decimos.

Lo que NO hacemos

  • Nadie paga por aparecer, destacarse u ordenarse mejor en este informe.
  • No mostramos precios de cierre como si existieran: son precios pedidos y está declarado en cada página.
  • No recomendamos comprar ni vender un inmueble específico — entregamos el mercado, la decisión es suya.
  • No rellenamos huecos: donde no hay dato suficiente, va "sin base suficiente", no un invento.
